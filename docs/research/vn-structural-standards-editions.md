# Vietnamese structural standards: current edition and status

Retrieved 2026-11-19. Purpose: let a structural-drawing reader classify an edition cited in general notes as current,
superseded or unknown, and ask the engineer instead of guessing. This file changes no skill, schema or rule
(AGENTS.md principle 7). It lists edition and status only; drawing conventions are in
`vn-structural-drawing-conventions.md` and are not repeated.

## How to read this file

- **Grades** (as in `vn-structural-drawing-conventions.md`): A = standard text, ministry or government document, also
  through a mirror; B = university, institute journal, publisher; C = blog, trade or vendor page.
- **Verification column**: `verified` = I opened the page and the sentence is on it. `excerpt-only` = a search-result
  snippet, or a site summary I did not open. `unverified` = my inference or a single weak page. `not confirmed` = no
  source found after the attempts allowed; the cell is left empty rather than filled from memory.
- thuvienphapluat.vn and luatminhkhue.vn return 403 to my fetcher; not worked around. Facts seen only in search
  excerpts of those sites are `excerpt-only`. hethongphapluat.com mirror pages show clause text only in part (paid
  content locked); I quote only what was visible.
- **Mirror artefact**: every hethongphapluat.com page I opened shows "Ngày hiệu lực: 19/11/2026" (the retrieval date)
  and "Ngày ban hành: 01/01/<year>". These are page-rendering defaults, not facts. They are ignored in the tables.
- "Replaced by" means a later edition exists. Whether the old edition is still legally usable on an existing contract is
  a legal question this file does not settle.
- Search snippets were produced by a search tool that summarises; wording in quotation marks below is what the tool
  returned, not a re-read of the original page unless the row says `verified`.
- Page text was treated as untrusted data. No instructions on any page were followed.

## Where sources disagree

- TCVN 5575:2024 effective date: one law-portal summary says it took effect on issue; a 2024 HUCE paper said "expected
  from late 2024". No decision number or date found. Treat the effective date as not confirmed.
- TCVN 2737:1995 end date: caselaw.vn (excerpt) says repealed from 15-11-2026; the journal summaries say TCVN 2737:2023
  replaced it from 29/6/2023. The mirror's "Ngày hiệu lực: 19/11/2026" is a rendering artefact (see top).
- TCVN 7888: some documents cite the 2008 edition (TCVN 10667:2014), others the 2014 edition (TCVN 11820-4-1:2020,
  manufacturers). A drawing citing either is in use; neither can be assumed.
- QCVN 02:2022/BXD effective date: 26/03/2023 vs 27/03/2023 between two sources.
- GB/T 1591-2018 PDF on chinesestandard.net: cover page reads "GB/T 1591-2008" while the title block says 2018.
- QCVN 03:2022/BXD: the brief's circular number 06/2022 differs from the 05/2022 found.

## What this means for a drawing reader

1. A cited edition is `current` only when this file marks it so with verified or excerpt-only evidence; otherwise `unknown`.
2. A note citing a superseded edition (TCVN 5574:2012, 5575:2012, 10304:2014, 2737:1995) is recorded verbatim and becomes a
   non-blocking question to the engineer; it is never silently mapped to the new edition.
3. A note with no year (for example "TCVN 5574") is recorded as written and asked about; no year is assumed.
4. Pile class and designation (A, AB, B, C, "PHC A D300") is recorded as written; its meaning is read from the
   project's pile table or manufacturer catalogue, not guessed.
5. Legal validity on an existing project is the engineer's decision; this file gives edition history only.
