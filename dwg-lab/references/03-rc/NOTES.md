## Notation (how to read a callout)

| Style | Example | Reads as | Source status |
|---|---|---|---|
| US imperial | `#5 @ 12"`, `#4 Cont @ 1'-0"`, `#6 Cont`, `#4 (Tot 5)`, `6-#8` | bar size number (eighths of an inch), spacing o.c., "Cont" continuous, total count; leading integer = count | CDOT 4.3 gives `#4 Cont @ 1'-0"`, `#6 Cont`, `#4 (Tot 5)`; `6-#8` and the eighth-of-inch rule are general knowledge/snippets: unverified |
| US metric (DOT) | bar size by soft-metric number | not covered | not verified |
| UK/HK/SG BS 8666 | `T20-200`, `12T16-01-150`, `R8-02-250` | T = high-yield ribbed, R = plain mild steel (type letters R,T,D,H appeared in a BS 8666:2005 table fragment; meaning not verified); diameter; optional bar mark; spacing | **Unverified.** No primary or reliable free source found for the field order. Heaton page only shows `T20` and shape code 00 |
| Vietnam | `4Φ16`, `Φ16a200`, `Φ8a150` | count x diameter; `a` = spacing (center to center); Φ = diameter (and the prefix is sometimes bar grade, e.g. `AIII` or `CB400-V`) | TCVN 6084:1995 preview says the standard covers annotation of grade, diameter, spacing, number on leaders. The letter `a` and the exact reading are from general knowledge/snippet: **unverified** against TCVN 6084:2012 text |
| ISO 3766 style | per ISO: simplified representation with number, type, diameter, spacing | content paywalled | scope only |

Rule for the machine: parse with a regex per style, but **read the legend/general notes for the project's own convention first** and prefer the legend; flag any callout that fits two styles.

## Schedules: what to find

- **Footing/pile cap schedule**: mark, plan size (L x B x depth), bottom bars each way, top bars, column dowels, concrete grade, levels (founding level, top of footing); pile schedule: mark, diameter/size, length or tip level, capacity, cut-off level, reinforcement cage details, number of piles.
- **Column schedule**: mark, size, levels range, longitudinal bars (count and diameter, per face), ties (diameter, spacing; confinement zone spacing), concrete grade, splices (location/length).
- **Beam schedule**: mark, size, span (grid to grid), top/bottom bars at support and mid-span, stirrups (diameter, spacing, zones), side bars, level offsets.
- **Slab schedule/plan**: thickness, bottom mesh/bars each direction, top bars at supports (extent from face), distribution bars, openings.
- This field list is a synthesis from ACI 315R-18 chapter titles (foundations, walls, columns, beams, slabs), CDOT ch. 4 and general practice; field names are not quotes from any standard. DrawingVQA confirms that column, beam and footing schedules are core table content on real IFC drawings.
- **Bar bending schedule (BBS)**: member, bar mark, type/grade, diameter, number of members, bars per member, total number, length per bar, shape code (BS 8666 / ISO 4066 style) or bending diagram (CDOT: bending diagrams preferred, bar lists only when required), dimensions A, B, C..., mass. Vietnamese schedules (TCVN 4612:1988 per a search snippet; unverified) use: member name, mark, shape and dimensions, diameter, total length, mass.

## Cover, laps, hooks
- Cover: usually in the general notes with a table by exposure/member (e.g. CDOT lists 2 in generally, 1 in slab bottom, 3 in against earth). Never use a value from another project: read the notes.
- Laps/splices: CDOT 4.7 uses Class B splices from a worksheet table, lapped splices not above #11, splice quantities computed on stock lengths (40 ft for #5 and below, 60 ft for #6 and above). Heaton (C) quotes 35-45 d as typical in UK. Vietnamese values come from TCVN 5574:2018 (not read). **Do not hard-code laps.** If the drawing gives no lap, ask (quantity impact: TT13 5.6 and CDOT 4.12 include splices in quantities).
- Hooks: CDOT 4.6 treats 90, 135 and 180 degree standard hooks as not dimensioned unless non-standard; ACI 318 standard hook dimensions are tabulated (not read).
- Bend radii and shape-code length formulas change between BS 8666 editions (2005 vs 2020 changed how total length is computed per a supplier page: C). Use the edition cited on the drawing.

## One-page checklist (RC)
1. General notes: concrete grades per member, rebar grade/standard, cover table, lap/splice rule, hook/bend rule, tolerances, schedule conventions (are laps included?), code edition.
2. Legend: bar callout style, symbols for top/bottom bars, mesh notation, bar marks.
3. Plans/sections: locate every member mark; read reinforcement from sections and schedules; record which sheet holds which.
4. Schedules: transcribe row by row with sheet+revision+cell; check units (mm/m), diameter symbol, count vs spacing.
5. Cross-check: member mark on plan = row in schedule = section; bar mark used in sections = row in BBS; dimensions A+B+C vs member size minus cover.
6. Weight check: sum of bar length x kg/m (`0.006165 d^2` for d in mm; derivation in `../05-takeoff-qa`) vs BBS total mass printed by the designer.
7. Anything silent (lap, hook, cover, bar grade) -> open question; quantity marked provisional.

## Regional differences
- Notation, bar grades (CB300-V vs B500B vs Grade 60), size system (mm vs #n) and cover/lap tables differ completely by region. Schedule-vs-diagram preference differs (CDOT prefers bending diagrams; UK uses shape codes; VN uses a table with bending sketch).
- Vietnamese practice treats "thong ke cot thep" as part of the drawing; TT13 measurement rules (include laps and spacers) are for costing, not for drawing.

## Where sources disagree
- ISO 4066 year behind TCVN 5898 (1980 vs 1995 in snippets).
- Whether TCVN 5898 content was merged into TCVN 6084:2012: snippet says yes ("replaces both 6084:1995 and 5898:1995"); the mirror page for 6084:1995 shows replacement by 2012; I could not read the 2012 foreword. A search result itself notes the schedule content may not map one-to-one.
- CB600-V in or out of TCVN 1651-2:2018 (one snippet only).

## Gaps / unverified
- No free authoritative source for BS 8666 shape code list, ACI 315 bar types or ISO 4066 shapes; Scribd copies exist but were not used (copyright/quality).
- TCVN 6084:2012 and TCVN 5572:2012 full text not read; TCVN 5574:2018 not read.
- No dataset of real Vietnamese RC schedules found.
- Lap and cover tables deliberately left out.
